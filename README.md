# 📊 Análise de Vendas de E-commerce

Projeto desenvolvido para fins de estudo durante minha formação em Data Science.

O objetivo deste miniprojeto é aplicar conceitos de **limpeza, transformação, análise e visualização de dados** utilizando Python, transformando dados brutos de vendas de um e-commerce em informações úteis para apoiar decisões de negócio.

Além da análise proposta no curso, adaptei a estrutura original do projeto, que era apresentada em **Jupyter Notebook**, para uma aplicação utilizando **PyCharm**, ambiente virtual, versionamento com **Git e Git Bash** e execução centralizada através de um arquivo `main.py`.

---

## 🎯 Problema de Negócio

Uma empresa de e-commerce em crescimento possui um grande volume de dados de vendas, porém encontra dificuldades para transformar essas informações em decisões estratégicas.

Entre os principais problemas estão:

- dificuldade para identificar os produtos com maior e menor demanda;
- falta de clareza sobre quais categorias geram maior faturamento;
- dificuldade para identificar tendências e sazonalidades nas vendas;
- pouca visibilidade sobre as regiões com maior concentração de clientes e vendas;
- dificuldade para direcionar melhor os esforços de estoque, marketing e expansão.

O problema central é a falta de visibilidade clara sobre a performance do negócio, dificultando a tomada de decisões baseada em dados.

---

## 🔎 Objetivos da Análise

O projeto busca responder principalmente às seguintes perguntas:

### 📦 O que vender?

Identificar os produtos com maior volume de vendas, auxiliando na gestão de estoque e na identificação dos produtos com maior demanda.

### 💰 Onde focar?

Analisar quais categorias de produtos representam maior participação no faturamento da empresa.

### 📅 Quando agir?

Avaliar o comportamento das vendas ao longo do tempo, permitindo identificar tendências, períodos de maior movimentação e possíveis sazonalidades.

### 🌎 Para onde expandir?

Analisar a distribuição geográfica das vendas para identificar regiões com maior participação e possíveis oportunidades de expansão.

---

## 🧠 Solução Desenvolvida

Os dados são processados utilizando Python, passando por diferentes etapas de preparação, análise e visualização.

Durante o projeto são realizadas tarefas como:

- carregamento dos dados;
- tratamento e transformação das informações;
- conversão de colunas para formatos adequados;
- manipulação de datas;
- criação de novas variáveis;
- cálculo de faturamento;
- agrupamento de dados;
- identificação dos produtos mais vendidos;
- análise do faturamento mensal;
- análise por categoria;
- análise geográfica das vendas;
- criação de visualizações para facilitar a interpretação dos resultados.

O objetivo é transformar os dados brutos em informações mais claras e úteis para apoiar decisões relacionadas a estoque, marketing, planejamento e expansão.
